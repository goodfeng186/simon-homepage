02 QSA现状诊断

从"台账式静态合规"到"系统性动态协同"——问题诊断与升级路径

核心问题：台账式、静态化

当前QSA审核普遍流于 "台账式、打勾式" 静态检查：

  • 仅验证"有没有"——台账齐全、条款打勾、评审过关
  • 不评估"好不好"——运行实效与系统适配性未衡量
  • 不追问"佳不佳"——部门间联动与动态预警缺失
  • 分数波动不反映真实水平——取决于沟通/老师/文员表现
  • 审核归审核、干活归干活——采购流程没变、EC响应没快

QSA与全景图的三层结构

第一层 · 结果层
OQA → FQC 数据流
从客户反馈（外部OBA）到内部OBA，再到FQC数据反馈，形成完整闭环。当前内部OBA已突破，FQC数据成为当前数据重点。
第二层 · 流程层
按制度运行，非领导指令
世界顶尖企业按流程处理，我司仍有大量"参照流动性弱"、依赖临时协调的现象。EC/NPI样板使流程推行变为"有样板"可参考。
第三层 · 基础层
数据库与互联互通
互联互通已完成、专家咨询体系初具雏形、"工艺小阳"等标杆形成可复制方法论，为流程落地奠定基础。

06 重点流程深挖

用智能体五个维度 · 透视"从问题到工具 / 从工具到问题 / 从静态到动态 / 从应审到日常 / 从合规到诊断"

智能体五个维度 · 理解框架
用一个智能体的视角，统一解释 QSA 第一阶段为什么要变、怎么变。两个"五个"从不同切面观察同一件事：
五个维度（为什么变 · 目标态）
双路径 从问题到工具 · 从工具到问题
三转变 从静态到动态 · 从应审到日常 · 从合规到诊断
五能力（怎么变 · 智能体运行环）
感知 Perception → 规划 Planning → 工具 Tool → 记忆 Memory → 反思 Reflection
融合逻辑：五个维度是"目标态"（变到哪），五能力是"运行环"（怎么变）。下方用设备预警重点流程做完整示范。
模块A · 设备预警智能体
取自各部门任务-工艺准备部："设备维护从定期保养升级为状态监测+预测性维护"
流程背景： 原状——设备定期保养台账、坏了再修，单次停线损失大，年审前补点检记录； 目标——状态监测+预测性维护，异常提前预警，融入日常。
① 五个维度（为什么变）
维度在设备预警中的体现
① 问题→工具痛点：设备突发停线、事后维修被动 → 匹配"预测性维护智能体"（振动+温度+电流实时采集）
② 工具→问题已有：车间已部署传感器+数据采集平台 → 反向发现"定期保养"浪费（健康设备过度保养、亚健康设备没被发现）→ 改为"按状态保养"
③ 静态→动态静态：月度保养台账、纸质点检表 → 动态：实时健康度评分、异常秒级推送
④ 应审→日常应审：年审前补设备点检记录 → 日常：每天自动采集、健康度看板全员可见
⑤ 合规→诊断合规：有没有保养记录、点检表签没签 → 诊断：剩余寿命预测、维修优先级、备件需求预测
② 智能体五能力（怎么变）
能力在设备预警中的表现举例
感知
Perception		实时采集设备多源信号振动频谱、轴承温度、电机电流，每秒采样
规划
Planning		按异常自动定检修策略轻微→纳入下周保养；严重→立即停机派单
工具
Tool		调用业务系统执行动作自动开 CMMS 工单、查备件库存、调维修 SOP
记忆
Memory		沉淀设备全生命周期档案每台设备历史故障模式、维修记录、劣化曲线
反思
Reflection		复盘预警效果迭代模型误报率过高→调阈值；漏报→加特征，模型自优化
