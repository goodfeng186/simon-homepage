# 355 智能体系统 · 全网页演示版

这是一套纯静态网页演示包：不需要安装运行环境，也无需 PostgreSQL，不启动任何服务进程。用浏览器打开即可演示。

## 本地打开（file://）

1. 解压本目录（或直接进入本目录）。
2. 用浏览器打开 `index.html` 或 `login.html`。
3. 在 `file://` 下会跳过登录门，可直接查看各页。若仍从登录页进入：公司编码填 `DEMO`，工号和密码填 `demo`（任意非空工号与密码也可进入）。
4. 页面之间均为相对路径跳转。控制塔、SIP、知识库、检验、导入等页的操作只更新本机页面状态，并标明「演示数据，不写入服务器」。

## 用于 GitHub Pages

将本目录作为站点根目录发布，入口为 `index.html`。通过 `http://` 或 `https://` 打开时仍会检查本地演示令牌：请先在登录页进入，再浏览各子页。

本包不含后端、数据库目录或启动脚本，也不请求外部字体或脚本。从首页进入「体系 AI」可看脱敏示例问答，不需要密钥，也不请求网络。
